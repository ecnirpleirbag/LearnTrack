# Setup Instructions - LearnTrack

## Prerequisites
- JDK 11 or higher installed.
- Environment variables (`JAVA_HOME`) configured.

## Project Compilation
To compile the project from the root directory:
```bash
javac -d bin -sourcepath src src/com/airtribe/learntrack/Main.java
```

## Running the Application
To run the console application:
```bash
java -cp bin com.airtribe.learntrack.Main
```

## JDK Version Used
- Version: Java 21 (or latest available on system)
